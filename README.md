# 🚗 Racing Car Game

A 2D desktop racing game developed using **C#** and **Windows Forms**. Players control a racing car, avoid incoming traffic, earn points, and survive as long as possible while the game's difficulty increases.

---

## 🎮 Features

- Smooth player movement
- Obstacle generation
- Collision detection
- Score tracking
- Increasing game difficulty
- Game Over screen
- Restart functionality
- Keyboard controls

---

## 🛠 Technologies Used

- C#
- Windows Forms
- .NET Framework
- Visual Studio

---


## 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/RafyaJamil/RacingCarGame.git
```

2. Open the solution (`.sln`) file in **Visual Studio**.

3. Press **F5** or click **Start** to build and run the game.
