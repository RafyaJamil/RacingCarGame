# 🚗 Racing Car Game

A 2D desktop racing game developed using **C#** and **Windows Forms**. Players control a racing car to avoid incoming traffic, earn points, and survive as long as possible while the game's difficulty increases.

---

## 🎮 Features

- Smooth car movement
- Obstacle generation
- Collision detection
- Score tracking
- Increasing game speed
- Game Over screen
- Restart functionality
- Keyboard controls

---

## 🛠 Technologies Used

- C#
- Windows Forms
- .NET Framework
- Visual Studio
